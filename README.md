## 📌 Project Overview

This project investigates how **6G network performance** can influence **manufacturing efficiency in smart factories** using a data-driven approach.

The project analyzes important network parameters such as **latency, throughput, packet loss, bandwidth, and reliability** and studies their relationship with manufacturing performance indicators such as **production efficiency, machine utilization, downtime, and quality**.

The goal is to use **Data Analytics and Machine Learning** to identify patterns, measure relationships, and predict manufacturing performance under different network conditions.

## 🤖 Machine Learning

Machine Learning will be used to investigate whether network-performance parameters can help predict manufacturing efficiency.

Potential models include:

* Linear Regression
* Random Forest
* Decision Tree
* Gradient Boosting
* Other suitable models based on the dataset

Model performance will be evaluated using appropriate metrics such as **R², MAE, RMSE**, or classification metrics where applicable.
